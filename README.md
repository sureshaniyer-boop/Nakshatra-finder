# Nakshatra Finder V2

Static HTML version of `Nakshatra_7th_22nd_Tamil_Input V2.0.xlsx`.

This version can be hosted directly on GitHub Pages.

## Features

- Select Tamil nakshatra input
- Calculate 7th nakshatra from input
- Calculate 22nd nakshatra from input
- Show the full 27-position nakshatra cycle
- Show Tara Bala 9-cycle
- Show body part and sex reference columns
- PWA-ready files for Android home screen install

## GitHub Pages Setup

1. Upload these files to your GitHub repo:
   - `index.html`
   - `manifest.webmanifest`
   - `service-worker.js`
   - `icon.svg`
   - `README.md`
2. Go to the repository **Settings**.
3. Click **Pages**.
4. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Click **Save**.

Your app will usually be available at:

```text
https://sureshaniyer-boop.github.io/Nakshatra-finder/
```

## Android

After GitHub Pages is live:

1. Open the GitHub Pages link in Android Chrome.
2. Tap the three-dot menu.
3. Tap **Add to Home screen** or **Install app**.
